# COISBOL · Portal informativo

Portal informativo y dashboard del Centro de Observación e Investigación Social de Bolívar.

## Contenido

- Observatorio territorial con indicadores y gráficos.
- Panel de alertas y municipios priorizados.
- Información institucional y ejes de trabajo.
- Diez investigaciones aplicadas sobre protección, violencias, justicia y derechos humanos.
- Tres mapas interactivos con ZODES, violencia intrafamiliar y concentración municipal.
- Filtros interactivos y diseño responsive.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

La entrada activa es `index.html`, con estilos en `styles.css` e interacciones en `script.js`.
