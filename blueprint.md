# Blueprint: COISBOL Landing Page

## Overview

This document outlines the structure, design, and features of the COISBOL landing page. The goal is to create a modern, visually appealing, and informative website that effectively communicates the purpose and work of the Centro de Observaciones e Investigación Social de Bolívar (COISBOL).

## Design and Style

*   **Color Palette:**
    *   `--verde-institucional: #004c3f`
    *   `--amarillo-institucional: #f2c75c`
    *   `--blanco: #ffffff`
    *   `--gris-claro: #f4f4f4`
    *   `--texto-principal: #333333`
*   **Typography:**
    *   `--font-principal: 'Lato', sans-serif`
    *   `--font-secundaria: 'Roboto Slab', serif`
*   **Layout:** The layout is clean, modern, and responsive, with a focus on readability and visual hierarchy.

## Implemented Features

### Version 1.0

*   **Header:** A fixed header containing the COISBOL logo and navigation links.
*   **Hero Banner:** A prominent hero banner with a background image and a welcoming message.
*   **About Section:** A brief introduction to COISBOL.
*   **Purpose Section:** An explanation of the purpose of COISBOL.
*   **Footer:** A footer with contact information and social media links.

### Version 2.0

*   **Updated Content:** The content for the "About" and "Purpose" sections has been updated with more detailed information.
*   **New Sections:**
    *   **Importance:** Explains the importance of COISBOL.
    *   **Institutional Articulation:** Describes the institutional articulation of COISBOL.
    *   **Work Axes:** Presents the five axes of work in a card-based layout.
    *   **Research Lines:** Outlines the lines of research.
    *   **Research Projects 2025:** Lists the research projects for 2025.
*   **Updated Navigation:** The navigation bar has been updated to include links to all the new sections.

## Current Plan: Integrate New Information

**Objective:** To integrate the new information provided by the user into the existing landing page, creating new sections as needed and maintaining a cohesive design.

**Steps:**

1.  **Update Existing Content:** Replace the current text in the "Qué es COISBOL", "Importancia", and "Propósito" sections with the more detailed information provided.
2.  **Create New Sections:** Add new sections for the information that does not fit into the existing ones:
    *   Articulación Institucional
    *   Ejes de Trabajo (using a card-based design for visual appeal).
    *   Líneas de Investigación
    *   Proyectos de Investigación 2025
3.  **Update Navigation:** Modify the navigation bar to include links to all the new sections, ensuring easy access to the information.
4.  **Document Changes:** Update this `blueprint.md` file to reflect all the modifications and additions, maintaining a clear record of the project's development.
